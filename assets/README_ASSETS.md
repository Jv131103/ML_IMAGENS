# Assets — Fase 6

Imagens organizadas a partir dos resultados enviados para a conclusão do projeto.

## Pastas

- `01_labels_revisao/`: exemplos de bounding boxes/labels de teste.
- `02_yolo_comparacao_30x60/`: gráficos Precision, Recall, mAP@0.5 e mAP@0.5:0.95.
- `03_yolo_customizada/`: resultados visuais do melhor modelo customizado.
- `04_yolo_padrao/`: resultados da YOLO pré-treinada.
- `05_cnn_dataset/`: amostras do dataset usado pela CNN.
- `06_cnn_metricas/`: Accuracy, Loss e matriz de confusão.
- `07_cnn_previsoes/`: exemplos individuais de acertos e erros da CNN.

Você pode copiar diretamente esta pasta `assets_fase6_conclusao/` para o repositório e,
se desejar, renomeá-la apenas para `assets/`.
